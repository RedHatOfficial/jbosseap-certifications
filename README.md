# jbosseap-certifications

Jakarta EE Certification evidence for Red Hat JBoss Enterprise Application Platform.

This repository contains the [Technology Compatibility Kit (TCK)](https://www.eclipse.org/legal/tck.php) results that demonstrate JBoss EAP compliance with the Jakarta EE 10 specifications.
